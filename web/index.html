Загрузка программы…

Если программа не открывается

Файл index.html нельзя запускать двойным щелчком: браузер блокирует загрузку модулей и распознавание PDF через file://.

Для запуска без установки скачайте Windows-пакет, распакуйте его целиком и откройте Open-browser.cmd. Он запустит программу в вашем браузере; интернет для работы не нужен.

Отдельный архив Vedomost-Browser.zip предназначен для размещения на HTTPS-сайте.

# Ведомость

Программа для объединения спецификаций ЕСКД из PDF в Word с раскрытием сборок и указанием применяемости.

Готовые архивы доступны в [Releases](https://github.com/gabitofff-tech/vedomost/releases).

- Windows: распакуйте весь архив, запустите `Vedomost.exe`.
- Браузер без установки: запустите `Open-browser.cmd` из того же Windows-архива.
- Отдельная веб-сборка предназначена для HTTPS-хостинга и поддерживает офлайн-кэширование.

Python и интернет для работы готового Windows-пакета не нужны. Результаты распознавания необходимо сверять с исходными PDF.

Это предварительная версия. Веб-часть проверена в Chromium/Linux; нативный запуск EXE на Windows ещё не проверен.
